### 6. Fallback Semantics (WARNING)
- **Current Behavior**: The renderer uses `cmsValue || "fallback"`. Because `""` (empty string) is falsy in JavaScript, if an editor intentionally clears a field in the CMS, it will trigger the fallback, causing the old hardcoded text to reappear as a "zombie".
- **Desired Behavior**: Editors should be able to intentionally clear optional fields. `undefined/null` should trigger the fallback, but `""` should render as empty.
- **Recommended Resolution**: Change `||` operators to the Nullish Coalescing operator `??` in all `components/cms/renderers/*.tsx` and page components during Phase 5I remediation.
